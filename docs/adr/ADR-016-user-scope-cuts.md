## 用户指令原文

> 1、TTS 不做
> 2、转写本地插件有 whisper 就够了
> 3、语言模型我们不要本地自己接模型做，要和 memo 一样，接入在线模型 API
> 4、没有空间管理功能？
> 5、没有代理配置
>
> 追加澄清：
> 「那你已经做那两个留着。llm的理解你没错。空间管理指的是 memo设置里的第二项，
> 空间管理，不是工作空间，也不是知识库分区。不过对于我们来说似乎有没有都问题不大，
> 只要你的数据存放是独立文件夹且描述清楚即可，删除不要影响程序本体运行就好」

## 决策

### 1. TTS —— 不做

memo.ac 有（Kokoro）。我们不做。

### 2. 本地 ASR —— **不再扩容，但已做的保留**

- ❌ 停：sherpa 多模型族分派、SenseVoice / Qwen3-ASR / Omnilingual、AMD ASR 自建 CI
- ✅ 留（用户明确"已经做那两个留着"）：
  - **Paraformer**（ADR-013 的中文默认引擎，实测中文 1 小时录音 43 秒 vs turbo 22 分钟）
  - **sherpa 流式 zh-14M**（F3 实时字幕的唯一引擎）
- → memo.ac 47 条 ASR 模型 vs 我们 11 条的差距**接受**，不追平。

### 3. LLM —— **只留在线，砍掉内置**

- ❌ 砍：档 3 内置 `llama.cpp`（`llama-server` 线整体下线）
- ✅ 留：档 1 **BYO API Key**、档 2 **探测已装的 Ollama / LM Studio**
- 用户确认了这个分档理解："复用用户已装的"不算"我们本地自己接模型做"

> **✅ 执行补记（2026-08-08，由 `e2e-runtime` 就地补，依据 PROTOCOL §13）**
>
> **这条决策在 2026-08-08 之前只执行了一半，而剩下那一半是"活的"。**
>
> `vendor/manifests/models-llm.json` 里的 **5 条 GGUF** 一直留在清单里：
>
> ```
> llm/qwen3-4b-q4_k_m   llm/qwen3-4b-q5_k_m   llm/qwen3-8b-q4_k_m
> llm/qwen3-1.7b-q8_0   llm/gemma-3-4b-it-q4_k_m
> ```
>
> `[实测 2026-08-08]` 当时的真实状态：
>
> - **服务端没有任何过滤** —— `http/rest/manifests.ts` 已改成列目录加载所有 `*.json`
>   （那本身是对的修复，见该文件注释），于是这 5 条**确实到达 `/api/models/catalog`**；
>   对照实验：直接问加载器，`role=llm` 交出 **5 条**，总条目 35。
> - 只有 `apps/web` 的 `ASR_TAB_ROLES = ['asr','vad','punctuation']` 把它们挡在界面外。
>
> 也就是说它是**一个活着的 API 面，只是今天没人走**：
> `POST /api/models/pull` 直接喂 `llm/qwen3-8b-q4_k_m` 仍然能下载一个**本决策已经裁掉的东西**。
>
> **Manager 2026-08-08 裁定：关掉，并把历史写下来。** 依据：
>
> > **不许留半个功能。** 零读者字段最坏的地方不是浪费空间，
> > 是**下一个人会以为它在起作用**。而这条比零读者更糟 —— **它是活的，只是今天没人走。**
>
> **关在哪一层**：`apps/daemon/src/http/rest/state.ts` 的 `withoutRetiredRoles()`，
> 在 `loadModelCatalog()` **之后、构造 `RestState` 之前**把 `role=llm` 摘掉。
> 选这一层是因为 `/api/models/catalog` 与 `findCatalogModel()`（`pull` 的入口）
> **读的是同一份 `modelCatalog`** —— 一处收口，两条路一起堵。
> **刻意不在前端加过滤**：前端过滤是装饰不是闸门（Manager 明确划的底线）。
>
> **为什么不删掉 `models-llm.json`**：删文件会让下一个人看不出这里曾经有过什么、
> 为什么没了，于是很可能把它加回来 —— §13 那张表就是这么来的。
> 文件留着、服务端摘掉、历史写在这里，三件事一起才叫关完。
>
> **一个刻意的例外**：**已经装在盘上的记录不受影响**。`listInstalled()` 读的是
> `manifests/` 下的安装记录而不是这份目录 —— 用户此前装过的东西不该因为我们改了主意
> 就从界面上消失，那是"数据在界面上消失"那一族。这里关的是**新的下载入口**。
>
> 守卫：`apps/daemon/src/http/rest/retiredRoles.test.ts`（4 条，用**真清单条目**做夹具），
> 其中一条是**反方向**的：`asr` / `vad` 一条都不许被误伤 ——
> 一个"把什么都过滤掉"的实现同样能让另外三条通过。

### 4. 空间管理 —— **要做，范围是"数据目录管理"（用户补充后修订）**

用户第一次说"有没有都问题不大"，**但随后补充了完整要求**：

> 「数据位置我怕我没说清楚，补充一句，**需要可以进行定义，修改，移动，和统计大小**」

→ **所以这不是可选项，是四个具体功能。** 我第一版按"不做独立功能"记录，**记窄了**。

| #   | 功能                  | 归属                                                    | 状态                     |
| --- | --------------------- | ------------------------------------------------------- | ------------------------ |
| 1   | **定义** 数据目录位置 | daemon（`oss-scout`）+ 设置页 UI（`architect`）         | 已有 `--data-dir`，缺 UI |
| 2   | **修改** 到别的路径   | 同上                                                    | 未做                     |
| 3   | **移动** 已有数据过去 | daemon（`oss-scout`）                                   | 未做                     |
| 4   | **统计大小**          | `model-mgmt`（已有 `StorageSettingsPage` 磁盘占用分解） | 部分有，需接进设置页     |

另外三条基础要求：

- **独立文件夹** ✅ 默认 `~/.local/share/openmemo`，可用 `--data-dir` 覆盖
- **描述清楚** —— 设置页需写明数据在哪、各子目录装什么。
  ⚠️ 路径的**权威来源必须是 daemon**（`/api/health` 已返回 `dataDir`），前端不许猜
- **删除不影响程序本体运行** ✅ **已实测**：
  运行中 `rm -rf` 数据目录 → `health=200`；停掉重启 → 自动重建，`notes=200 selfcheck=200`
  ⚠️ **未测**：删除窗口内的写操作行为（SQLite 文件已删但 fd 仍开）

> **ADR-006 决策 4「不引入 workspace 层级」结论不变，但我当时的理由不成立。**
> 我写的是"日后加只需一列 + 一次迁移"——那更像给自己少做事找的借口。
> 现在结论正确是因为**用户明确说不需要**，不是因为我当初论证得好。

### 5. 代理配置 —— **补齐，优先级最高**

用户点名缺口。中文环境下**没有代理 HF / GitHub 根本下不动**，直接决定模型能否装上。

- 下载器侧（`model-mgmt`）：HTTP/HTTPS/SOCKS5 + 认证 + `no_proxy`，
  上游版本检测也走代理；设置页「测试连接」需区分**代理不通**与**上游不通**
- 子进程侧（`gpu-runtime`）：yt-dlp `--proxy`、ffmpeg 环境变量
- 与 ADR-004 的镜像多源探测**共存**，是两个维度

## 附：对外口径修正（`memo-compare` 查出我们吹过头）

- ❌「可导入任意 HF GGUF 模型」——**不成立**，`kind:'hf_repo'` 硬编码 501。
  用户已定"whisper 就够了"，该能力价值下降，**改口径不补实现**。
- ❌「真实 AMD 支持」——**只覆盖 LLM 不覆盖 ASR**（vulkan/rocm 包全是 llama.cpp）。
  ASR 侧 AMD 需自建 CI，按决策 2 不做，**改口径**。
- ✅ 站得住的：**量化选择**、**显存 fit 预检**（均已在运行实例上实测）。
