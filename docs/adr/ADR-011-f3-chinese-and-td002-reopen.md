## 0. Manager 自我更正：**TD-002 是我过早关闭的**

我在 ADR-008 决策 1 里宣布 TD-002 关闭，依据是"F1 真实 URL 在 yt-dlp 全关下跑通"。

`gpu-runtime` 在补跑长音频时发现：**`TranscribePipeline` 调 `resolve()`+`probe()`，
绕过了 T-020 加的 probe 回退链**。后果：
- **GPL 兜底在真实导入路径里从未触发过** —— TD-002 的解析顺序**在最关键那条路径上是摆设**。
- 第一个候选的瞬时网络错误会直接失败整个任务。

**我的错误**：我把"一个测试通过"当成了"这个性质成立"，而那个测试走的不是真实导入路径。
这正是本项目反复出现的"假绿灯"，**这次犯错的是 Manager 不是 agent**。

**处置**：已由 `registry.probeWithSource()` 修复 + 回归测试。**TD-002 现在是真的关闭了**
（有覆盖真实路径的回归测试为证）。
**教训写进验收标准**：以后验收"某性质成立"时，必须确认测试覆盖的是**产品真实路径**，
而不是一条为测试而设的旁路。

## 决策 1：中文模型策略 —— **采纳，但用"标注+默认过滤"而非"移除"**

### 实测证据（`Zh-Twitter.ogg`，CC BY 3.0，337s）
| | base | large-v3-turbo-q5_0 |
|---|---|---|
| ASR RTF | 0.055（18.2x） | **0.377（2.7x）** |
| 置信度均值 | 0.81 | **0.95** |
| 繁体泄漏 | 有 | **0/22 段** |

**base 中文不可用，不是"稍差"**：维基百科→**危机摆科**、百科全书→**摆科权书**、
华尔街日报→**花耳街日报**、印度孟买→**印度梦买**、迈克尔杰克逊逝世→**麦克尔结克训试事**、
谷歌/李开复→**古歌/李开夫**、乔治·W.布什→**乔志W不时**、752%→**752的**。
large-v3-turbo 上述**全部正确**。

### 裁决
不采用"移除 base/small"，改为 **catalog 加 `notRecommendedFor: ['zh']` 字段**：
- 音频语言/界面语言为中文时，**默认过滤掉**并给出明确说明。
- 用户仍可手动解除过滤（英文转写时 base 在弱机器上是合理选择，一刀切会误伤）。
- **理由**：`gpu-runtime` 的顾虑是对的（"会让人以为产品很差"），但成因是**默认值**不是**可用性**。
  改默认值即可，不必删能力。
→ 指派 `model-mgmt`（catalog 归他）。

**繁简廉价解法已验证，采纳**：初始 prompt「以下是普通话的句子，请使用简体中文转写。」
可把 `對我做了介紹` 纠正为 `对我做了介绍`。已写进流水线中文默认参数。
⚠️ `gpu-runtime` 明确标注：**只解决字形，不解决准确率**。UI 不得据此宣称提升了准确率。

## 决策 2：**GPU spike 优先级上调 —— 从"性能优化"升为"中文可用性前提"**

中文必须用 large-v3-turbo，而它在 CPU 上只有 **2.7x 实时（1 小时录音要跑 22 分钟）**。
中文是主要用户群 → ADR-003 决策 3 的性质变了。

**`PENDING-USER-DECISIONS.md` 的 A-2（NVIDIA 机器）从"想知道"上调为最高优先级。**
这是目前唯一一个"缺硬件会实质影响产品可用性"的事项，其余待环境项都只影响验证覆盖率。

## 决策 3：包依赖的所有权规则修订（ADR-005 决策 3 的补充）

`gpu-runtime` 需要加 `sherpa-onnx-node@1.13.4`（Apache-2.0）但 `packages/pipeline/package.json`
不在其所有权内，只好用动态 `import()` 降级。**这是所有权表划得太死造成的摩擦。**

**修订**：某个包的 `package.json` 的 **`dependencies` / `devDependencies` 字段**，
由**该包 `src/` 的所有者**编辑，须在 inbox 申报。
根配置（`pnpm-workspace.yaml`、根 `package.json`、`tsconfig.base.json`）**仍归 `oss-scout`**。
→ 授权 `gpu-runtime` 自行添加 `sherpa-onnx-node`，并可保留动态 import 作为缺失时的降级。
