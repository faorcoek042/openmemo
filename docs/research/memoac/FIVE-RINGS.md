## 先答两句

1. **memo 第一次打开，不能立刻转写。** `[已核实]` 它自己的文案就是这么写的：
   `transcription.model not installed` = _"{{name}} model is not downloaded. **Please download a model first.**"_
   `model.download models` = _"**Please download models first.**"_
   ⇒ **memo 的"开箱即用"= 工具链就位（ffmpeg / yt-dlp / 三档引擎 / VAD / OCR 都在盒子里），
   但"转写"这一步仍然要先下模型。**
2. **五环上，memo 做了而我们确实缺的：只有一件 —— macOS 的 ffmpeg。**
   （yt-dlp 也算"它有我们没有"，但那是**我们有意不做**，理由是二进制内嵌 GPL。）
   **除此之外没有第三件。** 第 5 环（runtime 探测）**memo 基本没有这一环**。

## 二、逐环对照

### 环 1：下载（拿到那个包）

|                  | memo                                                          | 我们                      | 差距性质                       |
| ---------------- | ------------------------------------------------------------- | ------------------------- | ------------------------------ |
| 形态             | 单文件安装器（NSIS `.exe` / `.dmg`）                          | tar.xz / zip + 启动器脚本 | **有意**（免安装、可解压即用） |
| 体积             | 305 MB（解包 1.10 GB）                                        | 41–59 MB（v0.3.0 量级）   | 我们小一个量级                 |
| 内含别平台二进制 | ⚠️ **130 MB macOS dylib 塞在 Windows 包里**（1.10 GB 的 12%） | 无                        | **我们更干净**（别抄它）       |

**这一环没有缺口。**

### 环 2：开箱能用 ★ 唯一有真缺口的一环

| 组件                     | memo                                                       | 我们                                                                       | 差距性质                                                                     |
| ------------------------ | ---------------------------------------------------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| **转写模型**             | ❌ **一个都不带**（15 个 whisper 条目全带 `downloadLink`） | ✅ **带 3 个**（VAD 0.9 MB + whisper-tiny-q5_1 32.2 MB + sherpa 流式中文） | **我们更强**                                                                 |
| whisper 引擎             | ✅ CPU + DirectCompute + CUDA(18.2 MB 压缩)                | ✅ CPU + Vulkan(win/linux) + Metal(mac)；**CUDA 走下载(678 MB)**           | 见环 4                                                                       |
| **ffmpeg**               | ✅ **全平台内置** 194.7 MB（包里**零许可证文件**）         | ⚠️ **Linux/Windows 内置(LGPL)；macOS 仍下载**                              | 🔴 **缺口：macOS。且是供应商缺口不是选择** —— jellyfin-ffmpeg 不发 LGPL 变体 |
| **yt-dlp**               | ✅ 内置 18.45 MB                                           | ❌ 全平台下载                                                              | **有意不做**：二进制内嵌 mutagen GPL-2.0-or-later                            |
| VAD                      | ✅ 18.0 MB（含权重）                                       | ✅ silero-vad-ggml 0.9 MB                                                  | 相当（我们小得多）                                                           |
| OCR / bun / 字体 / jieba | ✅ 带（30.5 / 113.3 / 0.2 / 3.7 MB）                       | ❌ 不做                                                                    | **有意：范围外**（不在 F1–F5）                                               |

> ⚠️ **两类缺口必须分开说**（Coordinator 点名的那条）：
> **macOS 的 ffmpeg 是"没做到"**（供应商没有 LGPL 变体，我们卡在别人身上）；
> **OCR / bun 是"有意不做"**（不在 F1–F5 范围内）。**把它们混成一类会掩盖唯一那个真缺口。**

**⇒ 环 2 净判定：我们赢在模型（它 0 我们 3），输在 macOS 的 ffmpeg。**
**在"第一次打开能不能转写"这个判据上，我们能，memo 不能。**

### 环 3：还能下载更多模型

|               | memo                                                                                           | 我们                                                                | 差距                                             |
| ------------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- | ------------------------------------------------ |
| 通道          | `download-model` / `download-extra-model` / `check-model-exist` / `check-model-sha` `[已核实]` | `POST /api/models/pull` + `/api/models/catalog`                     | 相当                                             |
| 目录来源      | 远端热更新（`models.memo.ac/all-models`）`[报告]`                                              | 仓库内 committed 目录（诚实标 `stale:true`）                        | **取舍不同**：它更新快，我们可审计、不加出网依赖 |
| 下载源选择    | ✅ 有，且"未指定时系统自动选"（`preferences.download source hint`）`[已核实]`                  | ✅ `/api/models/sources/probe`                                      | 相当                                             |
| 导入本地模型  | ✅ `model.import model`                                                                        | ✅ `POST /api/models/import`（`local_file` 可用；`hf_repo` 硬 501） | 相当                                             |
| 校验          | `check-model-sha`                                                                              | sha256 + 逐文件校验                                                 | 相当                                             |
| 量化选择      | ❌ **无**（whisper 全 f16）                                                                    | ✅ 四档                                                             | **我们更强**                                     |
| 显存 fit 预检 | ❌ 无                                                                                          | ✅ `fitness.tier`                                                   | **我们更强**                                     |

**这一环没有缺口，我们两项更强。**

### 环 4：其他运行时支持

| 后端                  | memo                                               | 我们                                |
| --------------------- | -------------------------------------------------- | ----------------------------------- |
| Windows N 卡          | CUDA：包内 18.2 MB 压缩 + **用户另装 CUDA 运行库** | CUDA：**678 MB 随包运行库**，走下载 |
| **Windows AMD/Intel** | ✅ **DirectCompute**（D3D11，随包 0.9 MB）         | ✅ **Vulkan**（随包 25.1 MB）       |
| macOS                 | Metal + CoreML                                     | Metal（随包 2.0 MB）                |
| Linux                 | ⛔ **无 Linux 版**                                 | ✅ CPU + Vulkan                     | **我们独有** |

⚠️ **CUDA 那格的差别不是打包技巧，是内容**：memo 只放编译好的 `ggml-cuda`，
把约 560 MB 运行库推给用户（它的文档要求"确保 Cuda 驱动是 12.2"）；
我们把运行库随包分发。**它省的体积，是用户多出来的一个可失败环节。**

**这一环没有缺口**（Windows 非 N 卡两边都覆盖了，只是走不同后端）。

### 环 5：runtime 探测完成 ★ memo 基本没有这一环

| 步骤           | memo                                                                                                                           | 我们                                                     |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------- |
| 枚举硬件       | ⚠️ **有**：`check-device` / `get-graphics-card` / `get-device-manager-info` `[已核实]`                                         | ✅ `GET /api/runtime/hardware` + `openmemo-probe` 子进程 |
| **推荐后端**   | ❌ **没有**。`[已核实]` 全 locale **零条"推荐/适合你的显卡"文案**；界面是三按钮 `CPU / GPU / Cuda`，**出厂默认 CPU**，选错自负 | ✅ 有推荐                                                |
| 下载对应二进制 | ⚠️ 半：CUDA 靠随包 7z + 应用内下 cublas zip                                                                                    | ✅ 后端包 + 镜像 + sha256                                |
| 安装           | 解压到固定目录，**判据 = 文件存在性**（`checkWhisperCudaExist`）                                                               | ✅ 临时目录 → 校验 → 原子 rename                         |
| **自检**       | ❌ **只有存在性检查，没有"真跑一次"**                                                                                          | ✅ 真跑一次推理，结果写回清单                            |
| 显示状态       | ⚠️ 只有一个"View CUDA information"弹窗（原样贴 `nvidia-smi` 输出）                                                             | ✅ 每包状态徽章，区分"通过但没加速"                      |

**⇒ 环 5 memo 只做了第 1 步（枚举）和半个第 3 步。"检测→推荐→自检→状态"它没有。
这一环我们没有任何缺口，而且是我们领先最多的一环。**
