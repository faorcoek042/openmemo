SECTION 5 - CLOUD ASR ("online") PROVIDERS
=====================================================================
HOW CLOUD ASR WORKS IN THIS BUILD
  There is NO built-in / hard-coded cloud ASR provider table. Cloud transcription is dispatched
  entirely through the plugin system:
    - renderer builds its dropdown from  pluginProviders.filter(t => t.type === "transcription")
      and stores the result in transcriptSetStore.transcriptionProviders (initial value []).
    - main process, on transcriptType === "cloud", does
        ae.findIndex(Fe => Fe.value === A && Fe.type === "transcription")
      over getPluginProviders(); if nothing matches it throws
        "no provider found" / "no plugin found".
    - the selected plugin module is instantiated with its defaultsConfiguration merged with the
      user's stored configuration, and the audio path is passed in.
  Consequence: the set of cloud ASR providers is DYNAMIC and depends on which plugins the user has
  installed; it is not enumerable from the binary alone.
  Evidence tokens: transcriptionProviders (12 hits renderer), asrProvider* (14 hits renderer),
  asrInput (2 hits renderer), pluginProviders (12 main / 5 renderer), engine:"cloud".
