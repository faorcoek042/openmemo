0. WHERE SETTINGS LIVE (facts from MAIN bundle)
=====================================================================
  Settings file        : <userData>/conf/setting.conf   (JSON; evidence token: u8("conf/setting.conf"))
  Keyword/glossary file: <userData>/conf/keywords.json  (evidence token: u8("conf/keywords.json"))
  Workspace store      : electron-store  {fileExtension:"json", name:"index", cwd:"workspaces"}
  In-memory accessor   : gu(key) -> settings[key];  gu() -> whole settings object
  Mutation IPC         : ipcMain.handle("change-setting", (e, key, value) => ...)
  Read IPC             : ipcMain.handle("get-setting", (e, key) => ...)
  Validation IPC       : ipcMain.handle("check-setting", (e, serviceId) => ...)   (returns bool: is this
                         provider configured; special-cases "ernie" -> apiKey+secretKey, "notion" -> secretKey+pageId)
  On change, main broadcasts webContents.send("renderer-message", {type:"setting:change", data})

  IMPORTANT CAVEAT: setting.conf is an UNTYPED JSON blob. There is no JSON-Schema / zod / TS
  interface left in the shipped bundles, so an exhaustive key list is not statically derivable.
  Everything below is evidenced by an actual literal in the bundles.
